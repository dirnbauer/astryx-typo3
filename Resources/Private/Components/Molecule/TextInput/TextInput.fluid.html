TextInput — a single-line control, rendered as the bare `input` the stylesheet is written against rather than wrapped in a shell of its own. Three of its attributes are HTML booleans, and `disabled=""` is a disabled field: they genuinely cannot be emitted empty. Spelling each one as a two-branch f:if the way Button does would mean eight copies of the same tag for three independent flags, so the attribute name itself is what the inline f:if returns — the name, or nothing at all. `status="error"` also renders aria-invalid. The red border is a colour, and a colour on its own is not a message. `maxlength` is emitted whether or not it is set. An empty maxlength is not a valid non-negative integer, so the browser ignores it and the field has no cap — which is exactly what an unset argument should mean, and it saves doubling an already doubled tag for a third independent flag. `suggestInput` marks this field as the one the site's typeahead attaches to. astryx.js binds the dropdown to `[data-g-suggest-input]` inside a form, and a form may hold more than one input, so which of them is the query field has to be stated rather than guessed.
