DialogHeader — the title row of a dialog, an alert or a bottom sheet. Dialog writes its own header inline, which was fine while it was the only thing with one. AlertDialog, BottomSheet and BottomSheetSwitcher all need the same row, and three more copies of a heading, an id and a close button is three more places for the `aria-labelledby` wiring to drift. So the row is a component, and `titleId` is the argument that matters: whatever opens the header has to point its own `aria-labelledby` at the same id, and an id invented in here could not be named out there. The close control closes the dialog with `method="dialog"` rather than with the `data-g-dialog-close` hook astryx.js binds. Both end in `close()`, but the form does it with scripting off, and a modal that cannot be dismissed when a script fails to load is the worst failure mode this component has. Opening a dialog still needs the script — `showModal()` has no declarative equivalent — so this is one half of the pair coming for free, not both. Like Dialog's, the button appears only once it has a name: an icon-only control with nothing to announce is read out as "button", which is no way out of a modal.
