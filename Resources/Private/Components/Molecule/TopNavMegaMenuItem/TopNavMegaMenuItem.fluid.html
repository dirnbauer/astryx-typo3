TopNavMegaMenuItem — one described link inside a mega menu: a tile of an icon, a title and a line of prose saying where it goes. A link, always, because every one of them navigates. The icon is a slot holding a bare `svg`, and it has to be bare: the stylesheet paints the tinted tile with `.astryx-top-nav-mega-menu-item > svg`, so an icon wrapped in a span of its own arrives as an unstyled glyph. The title and the body are stacked by a wrapper this file's stylesheet adds. The item is a flex row — the icon beside the words — so without it the two lines would sit next to each other instead of under each other. `layout="drawer"` is the same entry inside the mobile drawer, where the tile becomes an indented row: the shared `.astryx-nav-item` class is added alongside this component's own, which is where that row shape lives. {ariaCurrent}{f:if(condition: '{selected} == \'selected\'', then: 'page')} {f:if(condition: '{layout} == \'drawer\'', then: 'astryx-nav-item')} {title}{body}
