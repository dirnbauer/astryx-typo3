Item — one row of a list, a menu or a result set. Three regions in one line: something leading (an avatar, a status dot, an icon), the label and its description in the middle, and something trailing (a badge, a timestamp, an action). `start` and `end` are named slots because they are genuinely separate regions with their own flex behaviour — the end region carries `margin-inline-start: auto` and pushes itself to the far edge — while the middle is ordinary content and stays the default slot. Passing `href` makes the whole row the link, exactly as the 1.x downloads list did: the row is then an and the hover, the pressed state and the focus ring belong to it. Without `href` the row is an
  • , and any link or button inside it gets the focus ring drawn around the whole row on its behalf. Those are the two shapes the CSS is written for, and which one you get is decided by whether the row navigates, never by an `as` argument. A selected row says so in ARIA as well as in the data attribute. The empty string is ARIA's own "not current", so the unselected case needs no branch.
