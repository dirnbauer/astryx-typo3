Item — one row of a list, a menu or a result set. Three regions in one line: something leading (an avatar, a status dot, an icon), the label and its description in the middle, and something trailing (a badge, a timestamp, an action). `start` and `end` are named slots because they are genuinely separate regions with their own flex behaviour — the end region carries `margin-inline-start: auto` and pushes itself to the far edge — while the middle is ordinary content and stays the default slot. Passing `href` makes the whole row the link, exactly as the 1.x downloads list did: the row is then an and the hover, the pressed state and the focus ring belong to it. Without `href` the row is an
  • , and any link or button inside it gets the focus ring drawn around the whole row on its behalf. Those are the two shapes the CSS is written for, and which one you get is decided by whether the row navigates, never by an `as` argument. The two flanking regions take a class of the caller's, because what sits in them varies in ways the row cannot know: a search result's trailing badges want their own gap and a top alignment, a download row's do not. What stays the component's is the region itself — the class that pushes it to the far edge is not something a caller should have to remember. One trap comes with the named slots, and it is Fluid's rather than this component's: a call that contains even one `` stops collecting its loose children as the default slot. Content meant for `` has to be spelled `` too, or it renders as nothing and nothing warns you. A selected row says so in ARIA as well as in the data attribute. The empty string is ARIA's own "not current", so the unselected case needs no branch. One attribute, not two: a caller's `ariaCurrent` says which kind of current this row is — `page` in a menu of pages, `true` where there is nothing more specific — and selecting a row without saying so falls back to `true`. The first version wrote both onto the same tag, and a duplicate attribute is resolved by the parser taking the first and discarding the second, which meant `selected` never reached ARIA at any call site that also set `ariaCurrent`. {ariaCurrent}{f:if(condition: '{selected} == \'selected\'', then: 'true')}
