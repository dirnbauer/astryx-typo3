Without it a list of seven checkboxes is read as seven unrelated switches, and "Vegetarian" on its own is not an answer to anything. The legend is only rendered when there is one. A fieldset whose grouping is already stated — the list is the whole of a labelled Field, say — should not say it twice, and an empty `` is a blank line the reader still stops on. Inside a Field the fieldset reset comes from `.astryx-field fieldset`, so this class mostly matters standing alone; `orientation="horizontal"` is the exception, and it is written on two classes precisely so it outranks that descendant rule and the row survives inside a Field.
