Feature — an icon over a short title and one paragraph: the most repeated shape in the whole catalogue. The glyph is decorative and says so. It never carries information the title beside it does not already give, so it is `aria-hidden` and the tinted square around it is the only thing a screen reader could have announced — which is nothing worth announcing. `icon` is a key from the shared icon vocabulary rather than a slot, because the CSS sizes the glyph through `.astryx-feature-icon > svg` and a caller passing its own markup would have to reproduce that contract exactly.
