TreeList — a nested list of rows: a file tree, a page tree, a taxonomy. role="tree" is claimed only when the list is given a name, and that is deliberate. The role brings the whole tree keyboard contract with it — arrow keys, one tab stop, an expanded state on every branch — and a server-rendered list of links honours none of it. Named, this is a widget somebody has wired up; unnamed, it stays an ordinary nested list, which every browser and screen reader already handles correctly.
