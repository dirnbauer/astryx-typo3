Table — rows of data. Astryx v0.6.0 gave TableHeader, TableBody and TableFooter components of their own. Server-side they earn nothing: a template writes its rows straight into `thead`, `tbody` and `tfoot`, and the stylesheet already reaches those bare tags. They are named slots here instead, so a caller can still fill one region at a time without three more components to resolve. The default slot comes first, before any of them, and that ordering is the one real decision in this file. A table's `caption` has to be its first child or it is not the table's accessible name, and a template that hands this component a whole table body writes its own caption at the top of that markup. Putting the raw slot first means both spellings — whole markup, or region by region — produce a conforming table. `scroll` asks for the horizontal scroll container around it. A table is the one element that cannot be made to fit a narrow column — a five-column table in a 320px viewport either scrolls or breaks the page — and the wrapper is what takes that scroll so the page never does. It used to be written by whoever placed the table, on the grounds that `astryx-table-wrap` is a second root class; eight elements then wrote the same div, which is how a convention rots. It is rendered here and the caller asks for it by name.
