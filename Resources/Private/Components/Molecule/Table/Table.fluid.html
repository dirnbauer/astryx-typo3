Table — rows of data. Astryx gives TableHeader, TableBody, TableFooter, TableRow, TableCell and TableHeaderCell components of their own, and so does this library — a header cell wants its `scope`, and a cell wants `data-truncate`. The three region components are also named slots here, because the stylesheet reaches the bare `thead`, `tbody` and `tfoot` too and a template that writes them directly is not wrong. The default slot comes first, before any of them, and that ordering is the one real decision in this file. A table's `caption` has to be its first child or it is not the table's accessible name, and a template that hands this component a whole table body writes its own caption at the top of that markup. Putting the raw slot first means both spellings — whole markup, or region by region — produce a conforming table. `scroll` asks for the horizontal scroll container around it. A table is the one element that cannot be made to fit a narrow column — a five-column table in a 320px viewport either scrolls or breaks the page — and the container is what takes that scroll so the page never does. It is ScrollableArea rather than a `astryx-table-wrap` div of this component's own: that container was the same three declarations, minus the tab stop and the focus ring, and a scroll container a keyboard cannot reach hides the columns it scrolls to from everyone who does not use a mouse — which is what a design review across every element reported, on ten pages at once. `scrollLabel` names it. Once the container is a tab stop a screen reader stops on it and has to be able to say what it is, so pass the table's subject; without one it is still reachable, just announced as "group".
