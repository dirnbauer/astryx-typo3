CodeBlock — a fenced block of source, on the theme's syntax surface. The listing itself stays with the caller, and for once that is not about wrappers. Code has to be escaped rather than rendered, and in TYPO3 it has to be escaped differently depending on who is looking: in the frontend the text is left exactly as typed, while in the editor the same field goes through `f:render.text` so the block becomes inline-editable — and that turns every newline into a break, which inside preformatted text is a line the reader would copy. Only the template knows which of the two it is in, so `pre` and `code` belong to it. What is left here is the frame and, when it is given one, the header strip: a file name, a language, a copy button. It is written only when it is filled, because an empty header still draws its rule across the top — and the test trims first, since a fragment written over several lines is never empty: it holds its own newlines. A listing is plain text, and there is nothing here to highlight it with — no script, and no server-side highlighter in the extension. The token colours and the highlighted-line rule that used to sit in the stylesheet styled spans nothing emitted, so they are gone; the syntax tokens stay in the theme for whoever brings a highlighter. `scroll` puts the listing in its own scroll container. A block beside a column of prose has a width the source does not fit in, and something has to take the overflow; without the container the widest line of code decides how wide the band is. It is asked for rather than assumed because a block set to wrap its lines has nothing to scroll.
