SectionIntro — the eyebrow, heading and lead that open almost every content element. The three parts are one component because the spacing between them is a relationship, not three independent margins, and because every element in the catalogue was repeating the same conditional cluster with its own class name. Each part is still its own atom underneath, so the type scale, the colours and the heading levels stay in one place. Each part is a named slot as well as an argument, and the slot wins: {data -> f:render.text(field: 'eyebrow')} {data -> f:render.text(field: 'header')} {data -> f:render.text(field: 'lead')} A slot carries what f:render.text returns as markup, which is what lets the visual editor edit the part in place. A string argument cannot: Fluid casts the value to a plain string on the way in and the template escapes it again on the way out, so the editor's markup arrived as visible text and an ampersand as `&amp;`. The three arguments are `mixed` for the same reason — they still work, and now pass that markup through unescaped too — but a slot is the way to write a new call site. A part whose slot renders nothing but whitespace counts as empty, so a fragment wrapping an empty field adds no empty paragraph. Once any fragment is named, Fluid hands the component nothing outside the fragments: whatever else belongs to the introduction — a byline, a date, a link back to the parent page — goes into an unnamed , which is the default slot and renders after the lead. A call site with no fragments at all is one default slot, which is how the catalogue composed the atoms by hand before the slots existed, and still works. `headingLevel` defaults to 2 because the page title is the document's only h1 and a section heading sits directly under it. An element that has to look larger says headingType="heading-1" rather than claiming the page's level. The lead is secondary-coloured at the large step, which is what the catalogue's intros wrote by hand two hundred times; `leadType` and `leadColor` change it. The stylesheet owns the column, the gap between the parts and the reading measure of the lead; there is no outer margin, because the Stack around an intro is what spaces it from the content below. `align` is `default` (the start edge, which `start` also names), `center`, or `end` — `right` is accepted for the header position of a core content element.
{eyebrow} {heading} {lead}
