SectionIntro — the eyebrow, heading and lead that open almost every content element. The three parts are one component because the spacing between them is a relationship, not three independent margins, and because every element in the catalogue was repeating the same conditional cluster with its own class name. Each part is still its own atom underneath, so the type scale, the colours and the heading levels stay in one place. `headingLevel` defaults to 2 because the page title is the document's only h1 and a section heading sits directly under it. An element that really is the top of its page, such as an article header, says level="1" rather than styling an h2 to look like one. Everything is optional: an element with only a heading renders only the heading, and the default slot carries whatever else belongs to the introduction — a byline, a date, a link back to the parent page.
