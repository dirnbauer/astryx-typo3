Blockquote — a quotation set apart from the text around it. Only the words go in here. The person who said them is a Citation, placed after this element inside a Figure, because HTML is explicit that an attribution is not part of the quotation: putting the name inside the
makes a screen reader read it as something the speaker said about themselves. The accent rule down the inline start edge is the quotation mark. There is no decorative glyph, so a quote still reads as a quote when the stylesheet fails and when it is copied into plain text.
