Pagination — the row of page links under a list of results. The controls row and the "page 3 of 9" line are two different things: one is a set of destinations, the other is a sentence about where the reader has got to. The sentence is a slot of its own so it never lands inside the flex row that spaces the buttons, and `astryx-pagination-controls` is left to the caller, which is where every existing pagination already writes it. The current page belongs in the markup as a `span` carrying aria-current="page" rather than as a link to itself; the stylesheet paints it from that attribute, pairing a tint with a weight so it stays findable in a theme whose accent sits close to the text colour.
