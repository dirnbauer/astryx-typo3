ChatSendButton — the control that submits the composer. A real `type="submit"` inside a real form, which is the one part of a chat interface that needs no script at all: the browser posts the field, the server appends the turn and the page comes back with it. It also gets Return-in-the-form and the implicit-submission rules for free, which a div with a click handler does not. It composes Atom/IconButton rather than restating a button. The square, the hover, the press and the focus ring all live there, and this file only names the glyph and keeps the send button's own class on the element so the composer's grid can find it. `ariaLabel` is the whole label. The arrow is drawn `aria-hidden` — the glyph has no accessible name of its own and without the label the control is announced as "button" and nothing else. The default glyph can be replaced through the slot for a theme with its own send mark.
