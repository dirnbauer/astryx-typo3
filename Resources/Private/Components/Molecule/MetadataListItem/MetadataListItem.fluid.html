MetadataListItem — one label-and-value pair of a MetadataList. The div around the
and the
is deliberate and is allowed inside a description list: it makes the pair a single grid child, so that a multi-column MetadataList moves the label and its value together instead of breaking them across a column boundary. Without it the two are separate grid items and a pair can end up split. The term is a named slot rather than a string because it often carries an icon or a link beside the word, and the value is the default slot because it is the part callers always fill. The pair is written only when that term slot is filled. Ten call sites hand this component a `dt` and a `dd` of their own instead — the term is an Atom/Text rendered `as="dt"`, so that it takes the theme's label type and the element's own class — and wrapping those produced a `dd` inside a `dd` with an empty `dt` beside it. A caller who brings the pair now gets it through untouched; a caller who brings only the two halves gets them wrapped. It is the same rule Banner follows with its title. `preferred` is the editor's "this is the one we recommend", which a pricing element's own stylesheet tints the pair from.
