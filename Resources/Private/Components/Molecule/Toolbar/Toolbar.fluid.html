Toolbar — a row with a start, a centre and an end: the bar above a list, a sticky call to action, a strip of page links. `ariaLabel` decides the element, the way `href` decides Button's. A row of links that moves a visitor around the site is navigation and belongs in a `nav`; a `nav` with no accessible name is worse than no landmark at all, because a screen reader then lists an anonymous region. So naming the row is exactly what makes it one, and an unnamed row stays a plain `div`. There is no `as` argument, because the two are never a free choice. The two end regions — `astryx-toolbar-start` and `-end` — are named slots. They were the caller's own elements until 2.0, on the grounds that they carry the bar's own class beside the toolbar's; every bar in the catalogue then wrote the same two divs by hand. They are rendered here now, only when something fills them, and `startClass` and `endClass` are how a bar keeps the class it styles its own halves with. `-center` has no call site and so has no slot: a region nothing fills is a region nobody has thought about. An unfilled slot renders as null, so a bar with only a start region pays for nothing else — the same rule Card's media region follows.
