DropdownMenuRadioItem — one of the rows in a menu's radio group. `role="menuitemradio"` on a real `input type="radio"`, for the same reason the checkbox row uses a real checkbox: the exclusivity, the arrow-key traversal within the group and the checked state are all the platform's once the rows share a `name`, and every script-driven version of this pattern is re-implementing those three. `aria-checked` is left off here too — see DropdownMenuCheckboxItem for why a static one is worse than none. `name` is what makes the group a group. Radios that do not share it are three independent toggles that happen to be round, and nothing in the markup or the accessibility tree says otherwise, so the argument is the one a caller must not forget even though Fluid cannot insist on it: the row is useless without it, but a row with an empty name is still valid HTML and would fail silently. Raw attribute source, not an empty attribute: `form=""` is an id that matches nothing, and an input whose form attribute matches nothing has no form owner at all — not even the form it is written inside. form="{form -> f:format.htmlspecialchars()}"
