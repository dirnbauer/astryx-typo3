Overlay — content laid over media: a caption strip, a play button, a scrim that darkens a photograph enough for white text to sit on it. The root is the clipping container, so a scrim can bleed into the corners of a rounded image without a second border radius. The media goes in the default slot and the strip laid over it in `scrim`. That split used to leave a seam worth naming, and this is where it is closed. The contract maps this component's modifiers onto the root, which is where the data attributes below go, while the stylesheet still defines fill, dark, always and align-center on the scrim as bare classes — the CSS codemod does not touch those, because the scrim is not a root class. So the scrim is written here, from the very same arguments: the caller states the position, the tone and the reveal once, and this renders them twice, as the root's attributes and as the classes the stylesheet reads. Four elements used to write that class list by hand, and nothing kept it in step with the root. `reveal="hover"` means hover *and* focus, which is what the stylesheet does: a control that only appears when a pointer arrives is a control a keyboard can never reach. That is also why the two spellings differ — the argument says when it comes back, the class says which rule draws it. hover-revealfocus-reveal{reveal}
