Overlay — content laid over media: a caption strip, a play button, a scrim that darkens a photograph enough for white text to sit on it. The root is the clipping container, so a scrim can bleed into the corners of a rounded image without a second border radius. The media goes in the default slot and the strip laid over it in `scrim`. The root clips only to corners it has, and a square root put a square scrim over a rounded picture — dark corners standing out past the image's own. So the root takes the media's radius: by itself when the media is an AspectRatio (`radius="auto"`, the default), or as told with `radius` set to `element` or `container` for media rounded some other way. `none` keeps a full-bleed hero square whatever is inside it. Root and scrim carry the same four attributes because they describe the same arrangement from two sides: the root positions the strip, the scrim draws it. Stating them once here is what keeps the two in step. `reveal="hover"` means hover *and* focus, which is what the stylesheet does: a control that only appears when a pointer arrives is a control a keyboard can never reach. The scrim is drawn only when its slot has something in it, and that test trims first. A fragment written over several lines is never empty — it holds its own newlines — so without the trim a caller whose scrim is one conditional control would get a full-bleed dark panel over the picture on every record where the condition is false, and the clicks with it. {f:if(condition: '{position} == \'fill\'', then: 'fill', else: 'false')}
