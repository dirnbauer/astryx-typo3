Overlay — content laid over media: a caption strip, a play button, a scrim that darkens a photograph enough for white text to sit on it. The root is the clipping container, so a scrim can bleed into the corners of a rounded image without a second border radius. The scrim itself — `astryx-overlay-scrim` — is written by the caller, because it is the thing that varies: an element may lay one strip over its media or two, and one of them may be a button while the other is a caption. That split leaves one seam worth naming. The contract maps this component's modifiers onto the root, which is where the data attributes below go, while the stylesheet still defines fill, dark, always and align-center on the scrim as bare classes — the CSS codemod does not touch them, because the scrim is not a root class. Until one of the two moves, these attributes describe the overlay and the scrim's own classes style it. `reveal="hover"` means hover *and* focus, which is what the stylesheet does: a control that only appears when a pointer arrives is a control a keyboard can never reach.
