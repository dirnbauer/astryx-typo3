OutlineItem — one line of an Outline's "on this page" rail. The hairline the rail is drawn against belongs to Outline; the segment of it that the current entry paints belongs here, and the stylesheet takes it from `aria-current` rather than from a class. So marking an entry as current is one statement that both a screen reader and the marker read, and there is no second, visual-only spelling of it to fall out of step. `level` indents a nested heading. It is a bare class because `.astryx-outline-item.level-2` is what the stylesheet is written against — the class is not a component root, so the CSS codemod left it alone and the contract lists no modifiers here. Put the text in a `span`: the stylesheet truncates `.astryx-outline-item > span` at one line, and a bare text node has nothing to truncate.
