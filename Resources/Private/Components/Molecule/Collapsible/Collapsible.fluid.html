Collapsible — one disclosure: a summary you can click and a panel that opens under it. A native
. The open state, the keyboard behaviour, find-in-page finding text inside a closed panel and the printer expanding everything are all the browser's own, and none of them survive a div with a click handler. Nothing here needs scripting, which is the point. `name` puts this disclosure in an exclusivity group: opening one closes the others, again without a line of script. It is written only when it is set, because an empty group name is not a conforming one, and a page full of `name=""` disclosures would be relying on every browser agreeing to ignore it rather than treating them all as one group. `open` is written the same way. `chevronPosition` moves the marker to the leading edge. It renders `data-chevron-position` as upstream v0.6.0 expects; the CSS that acts on it has not been written yet, so today it is inert. A summary is a button to a screen reader, and a heading inside it is what lets a reader jump between the questions of an accordion instead of arrowing through all of them. `headingLevel` (2 to 6) is that heading: the summary slot is wrapped in an h2 to h6 that takes the summary's own type — its size, weight and family — rather than the page's heading scale, which would turn a question into a section title. Leave it empty when the slot brings its own heading, or when the disclosures are not a list of questions a reader would want to jump between.
