BannerTitle — the heading of a Banner. A real heading, at the level the surrounding document calls for, so that it appears where a reader expects it in the outline rather than being a bold line a screen reader walks straight past. The level is therefore an argument with no default worth guessing at: 2 is what a band-level note wants and is what Banner's own shortcut writes. Deliberately not Atom/Heading. A banner title sits at body size with a heavier weight, because it names a note rather than a section of the page, and a heading atom would bring the page's own type scale into a tinted box. The stylesheet says so explicitly now: until it did, an h2 here took the theme's h2 size from the reset layer — 25px in a box meant for 14px, four lines deep on a phone. `size="lg"` is the one step up, the large text size, for a banner that is the only thing in its band and has to be noticed from across the page. It is still not a section heading's size. `id` is the one attribute a caller reaches for here: a banner that names itself through `ariaLabelledby` needs its title to have something to point at, and an empty id is not a conforming one.
