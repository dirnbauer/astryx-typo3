Tab — one trigger in a TabList. A real `button`, so it is in the tab order, fires on Space and Enter and is announced as something that can be pressed. `role="tab"` then tells assistive technology it is one of a set, and astryx.js binds the arrow keys and the roving focus to exactly these elements: the script looks for `data-g-tab` inside a `data-g-tabs` boundary, so the hook belongs on the component rather than on whoever places it. `controls` is the id of the panel this trigger opens, and `selected` says which one starts open. Both are written as ARIA rather than as classes, because with the script absent the browser still has to be able to tell a reader what the row is: every panel stays in the page, and the first tab is the one marked selected.
