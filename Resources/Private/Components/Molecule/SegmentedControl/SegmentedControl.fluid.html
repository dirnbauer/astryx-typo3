SegmentedControl — a small track of mutually exclusive choices sitting on a tinted rail: a view switcher, a filter, a row of jump links. The one control in this set that swaps selection without a page load, so it must not reflow while it does: the stylesheet holds the label weight steady and signals the selected segment with a raised surface instead. Selection reaches the CSS through aria-selected, aria-checked or a checked radio inside the segment, so a build with no script, where the browser owns the state, still looks right. A list, because the segments arrive as `li` elements from the templates that use it and because a rail of eight jump links is something a screen reader should be able to count and skip. Note that the stylesheet sets no `list-style` on this class, so a caller with no sheet of its own will see the markers — the anchor bar removes them through the class it passes in.
