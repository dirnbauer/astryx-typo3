SegmentedControlItem — one segment of a SegmentedControl's rail. Which element is rendered follows Button's rule rather than being a free choice: `parameter` is a TYPO3 link field and becomes a TypoLink, `href` is a URL the template already resolved, and a segment that navigates is an anchor either way. A segment that toggles something without leaving the page is a `button`, and that is what neither argument means. The size is a bare class because `.astryx-segmented-control-item.sm` is what the stylesheet is written against; the class is not a component root, so the CSS codemod never moved it to a data attribute and the contract lists no modifiers here. Passing nothing leaves the segment at its default height.
