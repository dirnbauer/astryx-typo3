SideNavItem — one row in a SideNav, with or without a branch under it. The row itself is `.astryx-nav-item` plus this component's own class, worn together the way an icon button wears the button's class: the height, the hover tint, the focus ring and the truncating label live once on the shared row, and only the rail's own business — the collapsed width, the nesting indent — is written against `.astryx-side-nav-item`. Two shapes, and which one you get depends on whether anything was put in the slot. Empty, the row is a link (or a button when it has no href) inside an `li`. Filled, the slot is the branch: the row becomes the `summary` of a native `details` and the children a nested list inside it. That is why the child rows are the default slot rather than an argument — expanding a branch then costs no script at all, survives find-in-page, and prints open. A branch row is a `summary`, which means it toggles and does not navigate. A section that is both a page and a parent should be given the page as the first child row rather than made a link here: a control that both follows a link and opens a disclosure is one control with two jobs, and a keyboard user can only ask it for one of them. Selection is stated twice — `data-selected` for the tinted row, `aria-current="page"` for the announcement — because the tint says "you are here" only to someone who can see it. {ariaCurrent}{f:if(condition: '{selected} == \'selected\'', then: 'page')}
  • The chevron is the summary's last child because that is what the stylesheet turns when the branch opens — `details[open] > summary > svg:last-child`. It is hidden from assistive technology: the summary already announces itself as expanded or collapsed, and a second "arrow" in the announcement adds nothing.
