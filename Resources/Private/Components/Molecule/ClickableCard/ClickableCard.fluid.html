ClickableCard — the affordance that makes a whole card one link target. It adds no box of its own. The padding, the background and the shadow come from the Card it wraps; this component contributes the hover lift, the focus ring it borrows from the link inside, and the stretched pseudo-element that grows that link over the whole card. So there is exactly one in here, and it is the caller's — usually around the card's title. That keeps the accessible name of the target the title itself rather than "read more", and keeps the markup one honest link instead of a div with a click handler. A second link inside would get its own overlay and the two would fight, so put any further links outside the card. `as="li"` exists because two feature lists wanted a clickable row and reached for the class instead of the component — a `div` between a `ul` and its `li` is not a list any more, so the affordance had to become the list item rather than wrap it.
