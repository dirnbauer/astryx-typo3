Dialog — the native `dialog`, opened with showModal(). The element does everything a React modal needs a library for: the top layer, the focus trap, the Escape key and a real ::backdrop are all the browser's. The only script left is the click that opens it, and that script finds the dialog by id — which is why `id` is required here rather than optional. Naming it is the part worth spelling out. A dialog with a visible title is named by that title, so passing `title` writes the header and points aria-labelledby at it; a dialog that is nothing but a video has no heading to point at, so it takes `ariaLabel` instead. Both attributes are always emitted and the unused one is empty, which assistive technology ignores — branching the element would have meant two copies of everything inside it. The body wrapper is the caller's, because a dialog that scrolls and one that holds a single fixed-ratio frame want different things inside the same frame, and `astryx-dialog-body` is what makes only the first of them scroll. Overlay is a separate component and stays separate: a scrim over a picture is a decoration, a dialog is a mode. Sharing markup between the two would put a focus trap around a caption.
