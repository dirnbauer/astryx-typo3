Slider — a value picked along a line. The native ``, and only that. A drawn track and thumb would cover the cases a range input cannot express — two thumbs, a non-linear scale — but they are a pair of `
`s that move only when a script moves them, and there is no script here. A range input already drags, answers the arrow keys, Home and End, announces its value and its bounds, and posts. Choosing the one that works is not a close call, and the rules for the drawn pair are gone from the stylesheet rather than sitting there styling markup nothing renders. The vendor track and thumb pseudo-elements were only reachable inside a Field until now; the stylesheet reaches `.astryx-slider > input` too, so a slider on its own is painted rather than left to the platform. `valueLabel` prints beside the field, and it is the value the server rendered — it does not follow the thumb, because following it is script. Pass it where the page reloads on change, a filter with a submit button; leave it out anywhere the visitor drags and expects the number to move, where a stuck number is worse than none. The range input announces its own value to a screen reader either way. aria-valuetext is for a scale whose numbers are not the meaning — "Medium" over 2, "€40–60" over 3. Left empty the browser reads the number, which is right whenever the number is the answer.
