Link — an inline link, in the three weights the theme draws: underlined by default, `quiet` where the surrounding prose already makes it obvious that the words are a link, and `cta` where it reads as an action and grows an arrow. Which element is rendered follows from what the caller gives it, exactly as it does for Button: parameter a TYPO3 link field ("13 _blank - title", a mail address, an external URL). Resolved with f:link.typolink, which is the only thing that can turn "t3://page?uid=42" into a URL, and which also supplies the target and title the editor chose. href a plain URL the template has already resolved. `target` and `rel` therefore belong to the `href` form alone; in the TypoLink form the link field carries them. `rel="noopener noreferrer"` is emitted only for a target that opens a new browsing context, where it means something, rather than on every link.
