Link — an inline link, in the three weights the theme draws: underlined by default, `quiet` where the surrounding text already says it is a link, and `cta` where it reads as an action and grows an arrow. `parameter` and `href` are both here because a TYPO3 link and a web address are not the same thing. Editors store `t3://page?uid=42`, which only TypoLink can resolve into a URL, a title and — for an external target — the right `rel`; hard-coded addresses out of a template have nothing to resolve. `parameter` wins when both are given. `rel="noopener noreferrer"` is emitted only for a target that opens a new browsing context, where it means something, rather than on every link.
