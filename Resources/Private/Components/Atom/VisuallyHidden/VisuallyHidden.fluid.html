VisuallyHidden — text that is read aloud but never drawn. It is clipped rather than hidden. `display: none` and `visibility: hidden` both take the text out of the accessibility tree as well as off the screen, which would defeat the entire purpose; the stylesheet instead shrinks the box to a single clipped pixel, so the text stays in the tree and stays available to a screen reader. `as` is not decoration.
