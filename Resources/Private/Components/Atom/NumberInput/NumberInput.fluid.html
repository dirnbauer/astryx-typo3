NumberInput — an amount, with an optional unit beside it. Two anatomies, and the stylesheet's `:has()` guard is what tells them apart. With no unit it is the bare `` the shell styles directly. With a unit it has to be the wrapper form — the unit sits inside the field's border, sharing its row, and there is no way to put a second element inside an ``. Both are the same recipe; the wrapper draws the border and the input inside it goes back to being plain text. The unit is `aria-hidden` and also spelled into the label by the caller. Read aloud, "kg" after a number the visitor is still typing arrives in the middle of the value; in the label it arrives before it, which is where a unit belongs. The spinner buttons are gone (the stylesheet drops them) because they are a 12px target no theme can enlarge. The arrow keys still step the field, and `step` still decides by how much.
