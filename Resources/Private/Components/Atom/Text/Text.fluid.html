Text — one run of body copy at a chosen role in the type scale. `type` is the role, not the size: `supporting` is smaller AND quieter in colour, `code` changes family as well as size, and the display steps borrow the heading family. Asking for a size directly would get one of the three and miss the other two. `as` is separate from `type` for the same reason Heading keeps `level` and `type` apart. A definition term, a table caption and a figure caption all read as supporting text, but each has an element the browser and the screen reader already understand, and styling a `div` to look like them throws that away. The default is a paragraph because most text is one.
