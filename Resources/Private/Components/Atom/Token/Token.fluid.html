Token — a chip that names a thing: a tag, a subject, a filter, a category. A badge states, a token names, and the difference shows in what a token does: it is often the one the visitor is currently on, and often a link to the others. `selected` therefore says so twice, once as the data attribute the stylesheet reads and once in ARIA, because a chip that is only highlighted in colour tells a screen reader nothing about where the visitor is. `ariaCurrent` carries which kind of "current" it is — `page` for a set of category links, `true` where there is nothing more specific to say — and stays empty, and therefore false, on the others.   • `, which is what lets a screen reader count them; a token that navigates is a link, which is what makes it openable in a new tab. Both matter, so both are here, and `parameter` or `href` wins over `as` when the two disagree. {f:if(condition: parameter, then: 'typolink', else: '{f:if(condition: href, then: \'link\', else: as)}')} f:link.typolink is a ViewHelper, not a tag: it rejects any attribute it does not declare. The data and ARIA attributes therefore go through additionalAttributes rather than being written beside `parameter`, which is what a plain would allow and what the first version of this component wrongly did.
