Icon — one of Desiderio's semantic glyphs, sized by the box around it. The drawing is not this component's work and deliberately so: `g:icon` already owns the vocabulary of keys, picks the single icon library this theme draws, and emits the glyph as an inline SVG in `currentColor` with `aria-hidden` and `focusable="false"` set. Re-implementing any of that here would give the theme a second icon mechanism that could drift from the first. This component adds only what a glyph cannot carry itself: the box that decides how big it is and, where the icon is the only label present, a name for it. `color` paints the glyph from a token rather than from the text around it: `accent` for a marker that carries the brand (a takeaway, a highlighted point), `secondary` for one that should step back, and `success`, `warning` and `error` for the ticks, warnings and crosses of a checklist or a pros-and-cons list. `default` keeps the surrounding text colour. The colour never carries the meaning on its own — a tick and a cross differ in shape, and an icon that says something has an `ariaLabel` — so a reader who cannot tell green from red loses nothing. An icon beside text is decoration and stays hidden from assistive technology, because the text already says what the icon says. Passing `ariaLabel` is the explicit statement that this one is not decoration, and it is then exposed as an image with that name.
