Spinner — a ring that turns while something is being waited for. A spinner beside the word "Loading" is decoration and says nothing a screen reader has not already been told, so by default it is hidden from assistive technology. A spinner that is the only indication that anything is happening is not decoration: `ariaLabel` turns it into a live status region with a name, so the wait is announced rather than silent. The ring is drawn with one side transparent rather than as a full circle, because a complete ring looks identical at every angle and would appear static however fast it turned.
