Container — the measure a band of content is allowed to occupy, and the gutters that keep it off the edge of the viewport. The root class is `astryx-layout` and not `astryx-container`. That reads like a mistake and is not one: it is the name the theme stylesheet and every element template have carried since 1.x, and renaming it would orphan the CSS for the sake of tidiness. The contract records it as the historical root class for exactly this reason. `size` caps the measure in rem. `variant` carries the one opinion the CSS has that is not a width — `prose`, which caps the measure in characters instead, because long-form text stops being readable past roughly seventy of them however wide the screen is.
