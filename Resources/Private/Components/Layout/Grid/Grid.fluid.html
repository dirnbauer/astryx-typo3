Grid — a set of equal children laid out in columns. `cols` and `fixed` are not two spellings of the same thing. `cols` is a hint: the CSS reflows on the space the grid actually has, and the number only tunes the minimum a column may shrink to, so a three-column grid in a narrow sidebar becomes one column on its own. `fixed` is a promise: the count is held whatever the width, which is what a numbered three-step process needs, because reflowing it into two columns would misrepresent the process. Pass one or the other, never both. Neither is a modifier token, so neither is emitted when it is zero: an absent column count is genuinely absent rather than a grid of no columns. `as` exists because a grid of people or of steps is a list before it is a layout, and a list whose items are not in a `ul` or `ol` is announced to a screen reader as loose text with no count.
