LayoutContent — the shell's main region: the one pane that scrolls while the bar above it and the rail beside it stay put. A `main` element, so it is the main landmark and the target a skip link can aim at. `id` is worth passing for exactly that reason, and `tabindex="-1"` goes with it: without it, following a skip link moves the scroll position but not the keyboard, and the next Tab carries on from wherever focus still was — usually back up in the navigation the visitor was trying to skip. A -1 tabindex makes the region focusable by script and by fragment navigation without putting it in the tab order. Like the other three shell regions this is a region and not a design: it owns the scroll and the landmark, and what it looks like is whatever is placed inside it.
