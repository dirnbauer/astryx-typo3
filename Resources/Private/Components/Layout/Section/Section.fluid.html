Section — the root of every content element. Owns two things and nothing else: the vertical rhythm between one element and the next (`spacing`), and the surface the element sits on (`surface`). Everything inside it is somebody else's job. `frame` is the EDITOR's surface choice (tt_content.frame_class). It wins over the template's own `surface` default, so an element may ship an opinion and an editor may still override it from the backend form. The id branch is not duplication for its own sake: `id=""` is not a conforming HTML id, and anchor navigation is the one thing on this component a visitor can actually land on.
