Section — the root of every content element. Owns two things and nothing else: the vertical rhythm between one element and the next (`spacing`), and the surface the element sits on (`surface`). Everything inside it is somebody else's job. `frame` is the EDITOR's surface choice (tt_content.frame_class). It wins over the template's own `surface` default, so an element may ship an opinion and an editor may still override it from the backend form. `dismissible` marks the band astryx.js takes away when a `data-g-dismiss` control inside it is pressed — the script walks up to the nearest `[data-g-dismissible]`, so the attribute has to be absent rather than empty everywhere else, or the first dismissible offer on a page would take the section above it with it. Focus moves on to the next control after the band, so a keyboard is not dropped on the page body. `dismissKey` makes the decision stick: the band is remembered as closed in this browser for thirty days (`g-dismissed:` in localStorage) and removed again on every page carrying the same key — one key per offer, and a new key for a new offer, which every visitor then sees once more. Editors always see it: the runtime ignores the memory inside a frame, which is where the visual editor and the element library show a page. `surface="none"` paints nothing: the band lets whatever is behind it show, for content that brings its own surface. `elevation="floating"` takes the band out of the column and floats it over the page in the bottom corner of the window (across the bottom on a phone), sized to its content and lifted by a shadow — a corner card, an offer that waits to be dismissed. A floating band keeps its place in the source, so the reading and tab order stay where the editor put it; its default surface is the popover's, and a muted one is laid over that, because a see-through card over moving text cannot be read. `align`, `columns`, `variant` and `media` are the editor's choices that an element's own stylesheet keys off — `.g-team-grid[data-columns="3"] .g-team-grid__people`, `.g-footer-questions-band[data-media="yes"]` and the like. They were written straight onto the tag in 1.x; they are declared arguments now and render back as the same attributes, so 80 element stylesheets keep working untouched. Built as a fragment of attribute source, so the hook is absent rather than empty on the 249 sections that are not dismissible. The flag is a literal; the key goes through g:attribute, which escapes it and prints nothing for an empty one. `data-elevation` is printed only for a band that floats. data-g-dismissible="1"{g:attribute(name: 'data-g-dismiss-key', value: dismissKey)} data-elevation="floating" The id branch is not duplication for its own sake: `id=""` is not a conforming HTML id, and anchor navigation is the one thing on this component a visitor can actually land on.
