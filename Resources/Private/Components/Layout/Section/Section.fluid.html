Section — the root of every content element. Owns two things and nothing else: the vertical rhythm between one element and the next (`spacing`), and the surface the element sits on (`surface`). Everything inside it is somebody else's job. `frame` is the EDITOR's surface choice (tt_content.frame_class). It wins over the template's own `surface` default, so an element may ship an opinion and an editor may still override it from the backend form. `dismissible` marks the band astryx.js takes away when a `data-g-dismiss` control inside it is pressed — the script walks up to the nearest `[data-g-dismissible]`, so the attribute has to be absent rather than empty everywhere else, or the first dismissible offer on a page would take the section above it with it. `align`, `columns`, `variant` and `media` are the editor's choices that an element's own stylesheet keys off — `.g-team-grid[data-columns="3"] .g-team-grid__people`, `.g-footer-questions-band[data-media="yes"]` and the like. They were written straight onto the tag in 1.x; they are declared arguments now and render back as the same attributes, so 80 element stylesheets keep working untouched. Built as a fragment of attribute source, so the hook is absent rather than empty on the 249 sections that are not dismissible. data-g-dismissible="1" The id branch is not duplication for its own sake: `id=""` is not a conforming HTML id, and anchor navigation is the one thing on this component a visitor can actually land on.
