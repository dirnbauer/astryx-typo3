ThemeSwitcher — the light/dark control that sits with the header actions. Both icons are always in the markup and the stylesheet shows whichever one matches the scheme on screen, so the button never has to be re-rendered and never flashes the wrong glyph between paint and script. The scheme itself is a class on the document element, set before first paint by an inline script in the head; astryx.js binds to `data-g-scheme-toggle` here and writes the current scheme back onto this button as `data-g-scheme-state`, which is the hook the stylesheet and any future three-way label would read. The icons are decorative — the button's meaning is in its label, not in which of the two is visible — so they are hidden from assistive technology and the accessible name is carried by `ariaLabel` alone.
