SearchForm — the site search in the header: a field, a submit, and the loupe that collapses the pair. A real form that gets to the results page on its own, not a button that reveals one. It is visible by default and astryx.js collapses it on load, which is the order that matters: with the script absent a visitor gets a working search box rather than an icon that does nothing, and that is why the trigger only appears once the script has put `data-g-search-ready` on the form. `data-suggest` carries the tx_solr_suggest endpoint and is the single attribute the typeahead binds to — the same one EXT:solr's own search form emits, so this field and the one on the results page share an implementation without either knowing about the other. The dropdown hangs from `astryx-search__field` rather than from the input group, so it never becomes a flex item of the group and never inherits the seam rules that weld the group's segments together. `inputId` has a real default because three things point at it: the label's `for`, the trigger's `aria-controls`, and the script that moves focus into the field when it opens. An empty id would silently break all three.
Last in the row on purpose. Collapsed, this is the only thing visible, so it has to sit where the loupe belongs — the end of the header. Open, it turns into the cross that closes the field it follows, rather than a stray control floating to the left of it.
