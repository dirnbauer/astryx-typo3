SiteHeader — the bar at the top of every page: the brand, the main navigation, and whatever controls belong beside them. The navigation is written twice, once for the desktop row and once inside the mobile panel. That is not duplication for its own sake: the two are different landmarks at different breakpoints, and collapsing them into one list that moves between containers would need script to do what a media query already does. The panel is a native `details`, so it opens, closes and answers Escape with no JavaScript at all; astryx.js binds `data-g-menu` only to add the click-outside and the close-on-widen that the platform has no answer for. Everything this used to read out of the site configuration is now an argument, and the search field and scheme toggle arrive through the slot — both are conditional on settings, and a component that asked the global configuration what to render could not be rendered anywhere else. The skip link is rendered here, before the header rather than inside it, and that is the one surprising thing in this file. It belongs to the header because it exists only because the header has navigation to skip; it stays outside the `header` element because `.astryx-header` is sticky, and a sticky ancestor becomes the containing block of anything absolutely positioned inside it. The link is positioned against the page, so moving it in would move it on screen. It is also the first focusable thing in the document, which is the whole point, and that is only true out here. {skipLinkLabel}
The mark is drawn from currentColor, so it takes the theme's accent in every scheme without a second asset. {wordmark}
