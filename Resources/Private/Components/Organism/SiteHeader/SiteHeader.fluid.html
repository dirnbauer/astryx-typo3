SiteHeader — the bar at the top of every page: the brand, the main navigation, and whatever controls belong beside them. The navigation is written twice, once for the desktop row and once inside the mobile panel. That is not duplication for its own sake: the two are different landmarks at different breakpoints, and collapsing them into one list that moves between containers would need script to do what a media query already does. The panel is a native `details`, so it opens, closes and answers Escape with no JavaScript at all; astryx.js binds `data-g-menu` only to add the click-outside and the close-on-widen that the platform has no answer for. Everything this used to read out of the site configuration is now an argument, and the search field and scheme toggle arrive through the slot — both are conditional on settings, and a component that asked the global configuration what to render could not be rendered anywhere else.
The mark is drawn from currentColor, so it takes the theme's accent in every scheme without a second asset. {wordmark}
