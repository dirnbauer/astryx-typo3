Breadcrumb — the page chrome's own trail, rendered above the content. Distinct from Molecule/Breadcrumbs, and deliberately so: this one takes the rootline and writes the crumbs itself, because the page templates always have the same array to give it and nothing in a site's chrome varies. The molecule is the one to reach for when the crumbs are something else — a filter path, a folder trail typed by an editor. The last item is the page being read: text rather than a link, and marked aria-current="page" so assistive technology announces the position instead of offering a link to where the reader already is.
