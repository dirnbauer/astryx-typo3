SiteFooter — the foot of every page: the brand again, the languages the page exists in, the copyright line and the legal links. The active language is a `span` and not a link, for the same reason the last breadcrumb is: a link to the page a reader is already on adds an entry to a screen reader's link list and goes nowhere. Each alternative carries `lang` and `hreflang`, so the text is pronounced in its own language rather than in the page's. The year is taken from the clock rather than typed into a setting, because a hard-coded year in a footer is wrong for eleven months and nobody notices. `copyrightText` only replaces the name beside it.
