Form element "RadioButton": an Astryx RadioList — a fieldset whose legend is the question — with one RadioListItem row per option and the drawn radio. The row is the label, so the whole line is the hit target. Options are f:form.radio rather than RadioListItem itself, because only the ViewHelper registers the name with the form's request token. The legend follows the element's legendVisuallyHidden setting (the core default hides it); with renderFieldset off the group is a role="radiogroup" named by a visible label instead. {f:if(condition: element.properties.elementDescription, then: '{element.uniqueIdentifier}-desc')} {f:if(condition: validationResults.errors, then: '{element.uniqueIdentifier}-errors')}
