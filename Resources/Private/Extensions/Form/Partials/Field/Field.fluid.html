The shell around every Form Framework field: an Astryx Field with a real label (or a fieldset and legend), the control passed in as `elementContent`, the help text and the server's message. The contract is the core partial's — `element`, `elementContent`, `doNotShowLabel`, `renderFieldset` — so a field partial from another extension that renders Field/Field still lands in Astryx markup. The ids are the core's too: `{id}-desc` for the help text and `{id}-errors` for the message, which is what every control's aria-describedby names. "(required)" is text in the label, never a lone asterisk. As in the core, a field rendered as a fieldset reports its own errors (MultiCheckbox, RadioButton and AdvancedPassword do), so this shell only reports them for the plain case.
