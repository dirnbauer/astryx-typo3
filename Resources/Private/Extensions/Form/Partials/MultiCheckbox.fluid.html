Form element "MultiCheckbox": an Astryx CheckboxList — a fieldset whose legend is the question — with one CheckboxListItem row per option. The row is the label, so the whole line is the hit target. Options are f:form.checkbox rather than CheckboxListItem itself, because only the ViewHelper registers the name with the form's request token.
