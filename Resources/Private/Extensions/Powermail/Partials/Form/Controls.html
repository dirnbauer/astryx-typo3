The controls Form/FieldShell places, one section per Powermail field type. Every control is the bare element the Astryx stylesheet paints inside a Field — `.astryx-field :where(input, select, textarea)` is the input shell, the select chevron and the file button — so no control carries a class of its own. They are Extbase form ViewHelpers rather than Astryx's TextInput and friends on purpose: only the ViewHelpers register their names for the form's request token, and a field Powermail cannot map is a field whose answer is silently lost. `data` comes after `additionalAttributes`, so the errors-container set here wins over the one Powermail's validation attributes may carry.
