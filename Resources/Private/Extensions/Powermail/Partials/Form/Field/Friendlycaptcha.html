Powermail "friendlycaptcha" field (studiomitte/friendlycaptcha). The same three states Desiderio's partial has, drawn in Astryx markup: - bypass (Development context or test mode, decided by Desiderio's FriendlyCaptchaBypass, which this theme's parent set already uses to skip the check): an inert note that a captcha sits here; - the real widget, when the extension is installed and configured; - the extension's own "configuration missing" message otherwise. The widget lives in its own partial so the friendlycaptcha ViewHelper namespace is only parsed where the extension is known to be loaded — lib.astryxFriendlyCaptcha, set by a TypoScript condition, says so. The hidden "1" is what Powermail maps for the field; the widget writes its solution into a field of its own. {field.title}
