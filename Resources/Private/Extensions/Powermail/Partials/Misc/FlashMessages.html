Powermail's flash messages as Astryx Banners, tinted by severity. checkForTypoScript first: it is what queues the "TypoScript is missing" message when the Powermail set is not loaded, and that message is the only clue an integrator gets. It looks for `staticTemplate`, which Powermail only lifts out of `settings.setup` when the plugin has a FlexForm; a plugin with no form chosen yet has none, and would be told its TypoScript is missing when it is not — so the check is handed `setup` in that case.
