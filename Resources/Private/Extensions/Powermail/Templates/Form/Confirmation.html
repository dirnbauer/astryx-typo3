The "check your answers" step, when the plugin asks for one: a Card with the answers as an Astryx MetadataList (rendered by PowermailAll's web section) and two actions. Each action is its own form carrying every answer as hidden fields, the way Powermail expects: "Back" returns to the filled-in form, "Send" runs the create action. Plain Astryx button markup rather than the Button component, because Powermail's AJAX submit tells the two apart by data-powermail-form-ajax and the component has no slot for it.
