The heading of a core content element: SectionIntro, with the editor's header and subheader in it. The Layout field maps to the outline, with one exception. The page title is the document's only h1 — the page template renders it — so "Layout 1" asks for an h1's SIZE on an h2, which is what Atom/Heading's `type` exists for. Layouts 3 to 5 are h3 to h5; the default and "Layout 2" are h2, the level a band directly under the page title sits at. "Hidden" (100) renders nothing. The header and subheader go through f:render.text so the visual editor can edit them in place; `optional` keeps a record type without a subheader field from throwing.
