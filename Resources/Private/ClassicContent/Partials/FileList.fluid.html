The files of a core "File links" element, as Astryx List rows. Each row is one Item and one real link — the file's name — stretched over the whole row by the stylesheet, so a reader aiming at a row on a phone does not have to hit four words, and the accessible name of the target is still the file's name rather than "download". The Item stays an `li` rather than taking an href because a download wants the `download` attribute, which Item has no argument for. The editor's three switches decide what a row carries, as they do in fluid_styled_content: Display 0 name only, 1 with a file-type icon, 2 with a thumbnail for images (and the icon for everything else) File size the size beside the type badge Description the file's description under its name The icon key comes from Desiderio's file-type vocabulary, the same one the theme's Icon atom draws from — the engine's, not a second copy of it.
: {fileTitle} {file.description} {file.extension} {file.size}
