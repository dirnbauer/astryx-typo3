The frame every core content element and plugin sits in on an Astryx page. A core element — Text, Text & Media, a menu, a table — is one band, the same as any of the 250 elements this extension ships: a Section for the vertical rhythm, a Container for the gutters and the measure. It used to render through Desiderio's ClassicContent layout, whose section and container emit Tailwind utilities this theme never loads; the band was therefore unstyled markup with Desiderio's name on it. `id="c{uid}"` stays: it is what a section menu and every "#c123" link in an editor's rich text point at. The editor's Frame field (tt_content.frame_class) is honoured in the terms this design system has: none no band spacing — the element sits flush indent, indent-left/-right a narrower measure ruler-before/-after an Astryx Divider on that side A divider element is itself a separator, so it gets the tight band rather than a full one.
