Text & Images — the same template as Text & Media: the two CTypes differ only in which field the files processor reads (image vs. assets), and both arrive here as {files}. Kept as its own file rather than an alias so a site can override one without the other. Text beside or around media, in the Split layout the theme's own Text with Media element uses. The editor's "Position and alignment" (imageorient) is read the way core defines it: 0, 1, 2 above the text 8, 9, 10 below the text 17, 25 beside it, on the right 18, 26 beside it, on the left "In text" (17, 18) wraps copy around a float in fluid_styled_content; a two-column band is the Astryx answer to the same request, and it reflows to one column on a phone where a float would squeeze the copy. Beside the text, the copy stays first in the source and Split's `media-first` variant moves the picture to the left visually only, so the reading order and the first tab stop are the copy's either way.
