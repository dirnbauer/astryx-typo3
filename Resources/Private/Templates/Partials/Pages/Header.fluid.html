What is left in this partial is the site configuration and nothing else: which page the field posts to, what the brand is called, whether there is a scheme toggle at all. The markup is SiteHeader's, and the two controls that depend on a setting reach it through its slot — which is what lets the component be rendered somewhere that has no site configuration to ask. The field posts to the page carrying the search plugin. With no page named, the site root is the honest fallback: a query still lands somewhere real rather than reloading whatever page the visitor happened to be on. The suggest endpoint is the tx_solr_suggest page type, and it is resolved here rather than inside the component because which page type carries it is this site's arrangement, not the search field's business.
