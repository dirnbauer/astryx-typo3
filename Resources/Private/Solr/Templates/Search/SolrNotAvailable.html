Shown when the search server cannot be reached. It says so in the visitor's own words and stays a Banner rather than an error page: the rest of the site still works, and the navigation above is still the way on. Declared inside the section, not above it: a template or partial that is rendered through a layout or by section name never evaluates its root content, so a variable set out there is simply absent by the time the section runs — and every key built from it silently loses its path. Banner writes its own title and body wrapper once it is given a title, so all that is left here is the two strings and the tone. `ariaLive` rather than the role="status" this carried before: the results page replaces itself over AJAX, so a banner that arrives after the page did has to be announced — but the element is already a complementary landmark, and a role would take that away to say the same thing. The title is a real heading for the same reason: it is the one thing on the page at that moment, and it should be reachable as one.
