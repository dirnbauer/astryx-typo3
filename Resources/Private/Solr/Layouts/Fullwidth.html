The single-column shell, used by the standalone search box, the frequent searches list and by EXT:solr's own templates this theme does not restyle — overriding the layout by its upstream name is what puts those inside the Astryx container instead of leaving them in Bootstrap grid markup. `tx_solr` stays on the band. It is EXT:solr's own wrapper class and its AJAX layer finds the plugin through it, so it travels with the element whatever the element turns out to be.
