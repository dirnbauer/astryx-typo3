The results shell: filters beside the results on a wide screen, above them on a narrow one. The sidebar is rendered first and measured, because EXT:solr always fills the "extra" section — it just fills it with facet blocks that render to nothing when the query returned no facets. An `f:if` on the raw output would therefore always be true and every no-facet search would show an empty column, so the test is made against the text that survives stripping tags. `tx_solr` stays on the band. It is EXT:solr's own wrapper class and its AJAX layer finds the plugin through it, so it travels with the element whatever the element turns out to be.
