Declared inside the section, not above it: a template or partial that is rendered through a layout or by section name never evaluates its root content, so a variable set out there is simply absent by the time the section runs — and every key built from it silently loses its path. Active filters as removable Tokens. Each one is a link that removes itself, and its accessible name says so — "Remove Content type: Page" rather than a bare "×" that tells a screen-reader user nothing about what is about to happen.
