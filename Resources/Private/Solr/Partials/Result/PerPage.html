Declared inside the section, not above it: a template or partial that is rendered through a layout or by section name never evaluates its root content, so a variable set out there is simply absent by the time the section runs — and every key built from it silently loses its path. The select submits its form on change, which is the whole control — so the submit button is there for anyone whose JavaScript never arrives, and hidden from everyone else by the stylesheet. `orientation="horizontal"` is the point of the Field here, not an afterthought: that variant is display:contents, so the Field box dissolves and the label and the select land straight in the form's flex row, side by side, exactly as they did when the label was written by hand. The select stays a bare `select` because a Field paints one for free — `.astryx-field :where(select)` is the shell and the chevron — and the theme has no Select component to reach for.
