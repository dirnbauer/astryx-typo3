Tabs, TabList, Tab and TabPanel: the whole control is components. Every panel is in the page and none of them starts hidden, so the text is indexed, printed and searched in full. The shared runtime (`data-g-tabs` on Tabs) selects a tab, hides the panels that are not on show and adds the arrow keys, Home and End the tab pattern owes a keyboard; a strip too wide for a phone scrolls sideways by itself. Without the script the band is a stack of headed sections, divided by rules, longer but never broken. Each panel keeps its own heading for that case and for the outline; with titleDisplay="auto" it leaves the screen once the tabs work, because the selected tab already names the panel on show. The title is passed as plain text, which is what the panel's argument takes. {f:if(condition: data.header, then: data.header, else: tabsFallback)} {data -> f:render.text(field: 'eyebrow')} {data -> f:render.text(field: 'header')} {data -> f:render.text(field: 'lead')} {panel.title}
