{sitemap} is the page tree below this page, two levels deep. A content element renders through lib.contentBlock, which hands the template its own record and nothing else, so the menu the page templates get from lib.desiderioPageDataProcessing never arrives here: the processor is put on this CType in the theme's setup.typoscript instead. Pages hidden from the menu are skipped by the processor itself, which is the point of deriving the tree rather than curating it — nothing here can fall out of date, and nothing has to be maintained twice. Every page in the tree is a link, the top level included, so each branch is headed by its page as a linked h3 — the Heading component keeps a link inside it looking like a heading — with the pages under it as a List of quiet Links. (TreeList would make a branch a disclosure that opens rather than a page you can go to.) A page with nothing below it renders the intro and no list: an empty tree is a fact about the page, not an error. {f:if(condition: data.header, then: data.header, else: navFallback)} {data -> f:render.text(field: 'header')} {data -> f:render.text(field: 'lead')}
