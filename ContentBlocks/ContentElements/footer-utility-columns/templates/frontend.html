Place this only where the site's own template footer is switched off, or the page ends twice — this element renders the same kind of block that Partials/Pages/Footer.fluid.html renders, for pages laid out without it. It is still a content element, so it stays a section rather than claiming the footer landmark: a page with two contentinfo landmarks is a page whose landmark list has stopped meaning anything. An entry without a link opens the next column and becomes its h3. Count the groups — the first entry opens one, every later heading opens one. With the count on the list and each heading's own number, the stylesheet can spread whole groups evenly over however many columns are on screen.
