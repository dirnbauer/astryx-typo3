Each thumbnail links to the full-size file rather than opening a scripted lightbox. The browser's own image view zooms, rotates and saves, which is more than any overlay this element could ship — and it still works when the script does not load. The link says, out loud, that it opens a new tab. Every picture is cropped to AspectRatio's four-by-three frame, so pictures of mixed proportions still line up as an even grid; the original is one click away for anyone who wants the uncropped frame.
