Split is the two-column band, and it is used the way it is written: the copy first in the source, the picture second. Reverse asks Split for `media-first`, which moves the picture to the left in CSS and leaves the source alone — the copy is still read first by a screen reader and is still the first tab stop. On a phone the two columns stack in that order. The picture keeps its own proportions: it was chosen for what is in it, and a crop to a shape the element preferred would cut that out. Figure gives it the full column and the container's corners, and its caption. The action is a Button, and it is rendered only with both a label and a real target: a label with nowhere to go, or a bare "#" that reloads this page, is not an action.
