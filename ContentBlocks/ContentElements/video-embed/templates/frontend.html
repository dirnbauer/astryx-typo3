The player is a plain iframe inside AspectRatio's sixteen-by-nine frame, so the page does not jump when it loads and nothing has to run first. The poster sits behind the iframe rather than in front of it: a click-to-load poster would need a script, and an empty rectangle while the player connects is worse than a still frame the player simply covers. Without a video address the poster is shown on its own, in the same frame. A bare "#" is not an address: it would embed this very page. The iframe is named after the heading, or "Video player" when there is none — an unnamed frame is announced as "frame" and nothing else. {data -> f:render.text(field: 'header')} {data -> f:render.text(field: 'lead')} {data -> f:render.text(field: 'caption')} {data -> f:render.text(field: 'note')}
