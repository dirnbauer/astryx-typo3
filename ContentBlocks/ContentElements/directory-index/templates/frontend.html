The grouping is derived from the first character of each entry, so the editor never maintains the letters by hand. A first pass collects every letter once, in the order the letters first appear; the bar and the groups are both built from that list, and each group then gathers every entry that starts with its letter — so an entry typed out of order still lands in its group instead of opening a second "A". The bar lists the letters that ARE used rather than the whole alphabet with the unused ones greyed out: the element has no way of knowing what alphabet its language uses, and a hard-coded A to Z would be wrong the first time somebody indexes something in Greek. It is a SegmentedControl, the component for a rail of jump links. Each group is headed by its letter as a real h3, so a screen reader can move from letter to letter the way a sighted reader scans.
