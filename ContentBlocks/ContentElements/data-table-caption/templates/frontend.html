A real table with a real caption element, so the figures can be quoted with their heading attached rather than as five loose numbers. The column headings come from this block's own labels: the editor fills rows and never types a header row that could then disagree with the columns under it. SectionIntro opens the band; Table and its parts draw the grid, style the row headers and set every figure in tabular digits. The stylesheet only aligns the figure column to the end, where digits line up. At phone width the columns wrap rather than forcing a scroll, so the caption stays readable in full.
