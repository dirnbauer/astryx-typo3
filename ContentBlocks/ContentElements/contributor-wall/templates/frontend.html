Only the portrait and the name are rendered. Roles, biographies and the child's own text are ignored on purpose: the point of a wall is the number of faces, and two hundred people each carrying a job title is a directory, not an acknowledgement. Each cell is a supporting-size Text, so the names are set small by the type scale rather than by this element. A linked name inherits the link's colour; face and name are one link, never two. The portraits carry an empty alt. Every name is printed directly under its own picture, so a meaningful alt would read two hundred names twice — the one place in this group where naming the face costs more than it gives. Compact asks the avatar for its medium size and the grid for a smaller gap; the narrower columns follow from the tight section spacing the same switch sets. {person.title} {person -> f:render.text(field: 'title')} {data -> f:render.text(field: 'note')}
