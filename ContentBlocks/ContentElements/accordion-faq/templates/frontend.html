Every row is a native details element, and the shared name attribute is what makes them exclusive — opening one closes the rest without a line of script, and the keyboard, the find-in-page behaviour and the print rendering all remain the browser's own. The name is keyed to the record uid so that two accordions on one page do not close each other's rows, and the group carries the same name so the group and its rows can be seen to agree. The group draws the rules above the first row and below the last as well as between them.
