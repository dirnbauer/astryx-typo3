One flat list in a CSS column flow rather than a list per column: the editor's order stays the reading order either way, and a flow fills the last column instead of leaving it short. An entry without a link is a group heading — a real h3 under the band's h2, so the grouping a sighted reader takes from the column break also reaches a screen reader; the break itself carries nothing. This is a content element an editor drops into the page, not the site's own template footer — that one is rendered by Partials/Pages/Footer.fluid.html and keeps its brand, language and legal rows to itself. Count the groups — the first entry opens one, every later heading opens one. With the count on the list and each heading's own number, the stylesheet can spread whole groups evenly over however many columns are on screen.
