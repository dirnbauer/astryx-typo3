A CollapsibleGroup of Collapsibles, which are details and summary, so there is nothing to initialise and nothing to break: the open state, the keyboard handling and the accessible name are the browser's. Each row's summary is an h3 (Collapsible's `headingLevel`), so the rows are in the outline; the rows share no name, so several can be open at once. The group stands in open page, so it draws a rule above the first row and below the last (`dividers="all"`). The print rule in the stylesheet is the one thing the platform does not give. {data -> f:render.text(field: 'eyebrow')} {data -> f:render.text(field: 'header')} {data -> f:render.text(field: 'lead')} {entry -> f:render.text(field: 'title')} {entry.bodytext}
