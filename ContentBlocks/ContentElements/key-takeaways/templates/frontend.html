A point is a line of text, not a section, so it gets no heading of its own — six one-line headings would fill the page outline with entries that lead nowhere. The optional explanation sits under the point in the same item. The block's icon is the marker of every point, in the accent colour, and a point that picked an icon of its own shows that one instead. With no icon on the block (or "none"), List draws a plain dot. The glyphs are decoration and hidden from screen readers; the list itself already says these are separate points. {data -> f:render.text(field: 'header')} {data -> f:render.text(field: 'lead')} {item -> f:render.text(field: 'title')} {item -> f:render.text(field: 'text')}
