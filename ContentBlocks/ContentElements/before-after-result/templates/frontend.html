Nothing is computed here. The child's text field holds the starting value in the editor's own words — "was 2.4 %", "vorher 2,4 %" — and the value field holds where it ended up. The starting value is an , the element HTML has for a statement that is no longer accurate, and the arrow between the two is an Icon, hidden from assistive technology because the words already say which way round the pair reads. That also keeps the claim with the person making it: an element that subtracted one figure from the other would be publishing arithmetic nobody approved.
