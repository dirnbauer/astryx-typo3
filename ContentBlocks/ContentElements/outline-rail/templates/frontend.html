The rail is position: sticky, which means it travels as far as the column that contains it and no further. Dropped into a page's main column that is the height of this band; put in a sidebar column it follows the reader down the whole article. Neither case needs a line of script, and no entry is marked active because that would need a scroll spy, which does. A description typed onto an entry is ignored: the rail is one line per heading, and a heading that needs explaining is a section, not an entry. {f:if(condition: data.header, then: data.header, else: navFallback)}
