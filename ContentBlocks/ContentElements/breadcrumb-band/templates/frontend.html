{trail} is the rootline. A content element renders through lib.contentBlock, which hands the template its own record and nothing else, so the rootline menu the page templates get from lib.desiderioPageDataProcessing is put on this CType in the theme's setup.typoscript instead. The microdata is on the list rather than in a JSON-LD block, so the trail that search engines read and the trail a visitor reads can never drift apart. The last crumb is the page itself: no link, and aria-current says which one it is. A long trail wraps onto a second line rather than collapsing behind an ellipsis: knowing when it "no longer fits" is a measurement, and this catalog buys no element a script for that.
