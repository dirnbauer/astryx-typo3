The line under the figure is what separates evidence from marketing: an unexplained number is a claim, and a number with its method beside it is a measurement. It is therefore rendered small but never optional in practice. The figure is two Text atoms — the value at display size in the accent ink, the unit beside it in the quieter one — so its type comes from the type scale rather than from this element. It is not a Stat: a Stat is a description list, and with no label field there would be no term for the figure to describe. The quotation marks are the Blockquote's, in the language of the page.
