The tick carries its own name, because a mark that only means something by its shape is unreadable to anyone using the table without seeing it. The column headings are generic on purpose: which two subjects are being compared is content, and it belongs in the caption where both names fit. SectionIntro opens the band. Table and its parts draw the grid and style the row headers, Icon draws the mark, names it and colours it — success for a tick, the quiet secondary tone for a cross. The table only scrolls when a cell cannot wrap; at phone width the columns wrap instead, so the caption is never cut off.
