The photographs take their alt from the file itself. These are pictures of a workplace rather than portraits of named people, so the only person who can describe one is the editor who uploaded it — there is no field on this element that would know what is in the frame. The collage reflows on the number of pictures rather than on a variant switch: two columns whatever the count — the grid's small items keep two to a row on a phone too — and an odd last picture spans the row in a wider frame instead of leaving a hole beside it. Each frame is an AspectRatio, which crops, clips and rounds the picture; the element only decides which frame a picture gets. The single button sits in a paragraph of its own, so the copy column does not stretch it to the column's width.
