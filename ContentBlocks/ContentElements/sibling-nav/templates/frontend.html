{siblings} is every page under the same parent as this one. A content element renders through lib.contentBlock, which hands the template its own record and nothing else, so the menu is put on this CType by the theme's setup.typoscript rather than inherited from the page template. The rows are SideNavItems in a SideNavSection — the same rows a side navigation is built from, with their height, hover tint and focus ring. The page the reader is standing on keeps its place in the list and is marked as selected, which the item states twice: a tinted row for whoever can see it, aria-current="page" for whoever cannot.
