Composition only. The intro is a SectionIntro and each cell a Feature; the "card" variant makes the cell a Card that is itself the list item (Card as="li"), so every card in a row is as tall as the tallest. The "plain" variant drops the surface: a ClickableCard list item when the cell links, a bare list item when it does not. One link per cell, on the title: the title is already the accessible name, and one link is what lets the whole card become the target. The grid is a list, so a screen reader announces how many features there are. The editor's column count is Grid's `cols`, a ceiling: three means at most three, and fewer where three would be too narrow to read. Everything here is composed of components, so the element ships no stylesheet of its own. {data -> f:render.text(field: 'eyebrow')} {data -> f:render.text(field: 'header')} {data -> f:render.text(field: 'lead')}
