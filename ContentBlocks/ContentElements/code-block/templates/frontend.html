Two branches for one field. In the frontend the code is escaped and left exactly as typed, because f:render.text would turn every newline into a break element, and inside preformatted text that break is a line the reader would copy. In the editor the same field does go through f:render.text, so the block becomes an inline plain-text editable — there the breaks are the point. Long lines scroll sideways inside CodeBlock's own scroll container, which is a named tab stop: the keyboard reaches the overflow without the pre having to become a second scroller. The container is named after the heading, then the caption, then a plain "Code example". The copy button in the header strip is CodeBlock's: it copies the listing exactly as typed and announces "Code copied". Without the script it does nothing, and the code is still there to select. {data -> f:render.text(field: 'header')} {data -> f:render.text(field: 'caption')}
