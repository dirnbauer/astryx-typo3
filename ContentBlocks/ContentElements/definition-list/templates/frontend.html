A real description list. Each pair goes through MetadataListItem's term slot, which writes the dt and the dd inside one wrapper, so the term and its description stay one grid cell and cannot be pulled apart into different columns. HTML has allowed that wrapper inside a dl since 5.2. MetadataList lays the pairs out in two to four columns and rules each one off, so the eye can run down either side without losing its row. The value and its optional explanation are two blocks inside the dd: the value first, the explanation under it in supporting type. Everything here is composed of components, so the element ships no stylesheet of its own. {data -> f:render.text(field: 'header')} {data -> f:render.text(field: 'lead')} {item -> f:render.text(field: 'title')} {item -> f:render.text(field: 'value')} {item -> f:render.text(field: 'text')}
