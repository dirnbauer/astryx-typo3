The track is a scroll-snap row, so it is already a carousel with no script at all — drag, momentum and keyboard scrolling belong to the browser. The hook only adds the two arrows a mouse user has no other way to reach, and the shared runtime disables them at either end. The next card is deliberately left peeking past the edge: it is the only honest signal that the band continues, and it costs no markup.
