The whole row is the link, not just the title: a download row is one target, and a reader aiming at four words on a phone should not have to hit them exactly. Item becomes that link when it is given an href, so the typolink is resolved here first — a link field, a file reference or a page all come out as one URL. A row whose link resolves to nothing stays a plain row rather than a link to nowhere. The rows are a List in two to four columns, which reflows to one on a phone. The format and size go in the row's own description, because that is the one place an editor can keep them true — nothing here can read the size of a file that lives on another server. The square in front shows the file type the editor picked (a page when none is set, nothing for "none"); the arrow at the end says what the row does. {data -> f:render.text(field: 'header')} {data -> f:render.text(field: 'lead')} {f:uri.typolink(parameter: item.link)} {data -> f:render.text(field: 'note')} {item.title} {item.description}
