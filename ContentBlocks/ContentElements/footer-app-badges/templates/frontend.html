The badges are composed, not shipped as artwork: a flat clickable Card with the store's icon from the shared library and its name in text. Opening the page therefore fetches nothing from a store, no request tells anybody which app this visitor was shown, and a badge never goes out of date. The store name is the link, so each badge has an accessible name of its own; the card's clickable affordance spreads that one link over the whole tile. The badges are a horizontal List under the intro, and the QR code is an image an editor uploaded, set on a card so it keeps its quiet zone on any surface.
