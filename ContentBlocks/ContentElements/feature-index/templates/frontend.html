A List of Item rows flowed into CSS columns rather than laid on a grid, so a list of forty flows evenly and still reads top to bottom in each column: a grid would put the second entry beside the first and make an alphabetical order unusable. A linked entry is an interactive Item, which is itself the anchor, inside its list item; an entry without a page is the Item's own list item, unlinked, so it still appears. The one-line description is ItemDescription's `truncate`.
