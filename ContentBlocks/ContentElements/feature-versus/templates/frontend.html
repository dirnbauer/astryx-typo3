A real Table, because the contrast is two labelled columns read line by line and that is exactly what a table row is. Each row is headed by its point (a row header). The status quo reads in the secondary colour (Text's own `color`); the claimed column is the table's emphasised one — every cell of it, header included, carries `emphasis="accent"`, which tints the column and sets its heading in the accent colour. The first column header is visually empty on purpose: the row headings are the points, and naming them twice is noise. A header cell with nothing in it is announced as nothing at all, though, so the name is there and visually hidden. On a phone the table scrolls inside its own named region rather than taking the page with it.
