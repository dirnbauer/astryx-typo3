A Grid list of small flat Cards, one per tool, each card the list item itself. The editor's column count is held (`fixed`), and the items are small, so a phone keeps two to a row. A tile with a link is a clickable Card whose name is the link; one without stays a plain tile rather than an anchor that goes nowhere — a tool you cannot read more about is still worth listing, but not worth a dead click. The mark is a Logo: one height for every mark whatever its proportions, grey at rest and in its own colours under the pointer or the keyboard. The name is printed under it, so the mark is decorative and takes an empty alt; carrying the file's own alt text here made every tile announce the same company twice. Everything here is composed of components, so the element ships no stylesheet of its own. {data -> f:render.text(field: 'eyebrow')} {data -> f:render.text(field: 'header')} {data -> f:render.text(field: 'lead')} {logo.title} {logo -> f:render.text(field: 'title')} {data.cta_label}
