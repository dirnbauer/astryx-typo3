Only the title and the link of each child are rendered. A description or an icon typed onto one of them is ignored on purpose: sixty labels that each grew a second line would be a Page List Menu, and this element exists for the case where the label is the whole message. The links are a List in two to four columns — `columns` is a ceiling, so a narrow column of the page gets fewer — and each link is an Item with a one-line label: given a link field the Item is the link, so the whole row is the target, which a label this short needs to be reachable on a touch screen at all, and a label that is too long is cut with an ellipsis instead of wrapping.
