A summary, not a substitute. Which details an operator has to publish depends on the operator — legal form, trade, whether there is a periodical behind the site — so this element renders whatever pairs the editor typed and points at the full imprint page rather than pretending to be it. A real description list, so the pairs survive being copied into a document and a screen reader gets a term with its value instead of two columns of unrelated words: the small MetadataList, a rule under each pair, the short value first and the sentence explaining it under it. The stylesheet flows the pairs down the columns; `columns` is passed on so the list keeps the rule under every pair.
