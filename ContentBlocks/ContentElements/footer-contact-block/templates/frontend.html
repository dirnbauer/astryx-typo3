An address element, because that is what these details are — and each channel is one Item whose description (the channel word) comes before its label (the value) in the source, so a screen reader announces "Telephone, +43 2626 20156" rather than a number with no idea what it dials. The icon is decoration on top of that word, never instead of it. The link carries the tel: or mailto: URL and the value is its text, so the row works with one tap on a phone and still reads as a number on paper. The channels are a two-column List (one column on a phone) inside Text written as the address element, with the small FeatureIcon a contact row calls for. {channel.description} {channel.title} {channel -> f:render.text(field: 'title')} {data -> f:render.text(field: 'note')}
