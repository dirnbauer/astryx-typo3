Every profile link carries the network's name as text, so the row survives a reader who does not recognise a logo, an icon set that fails to load and a screen reader — the icon is a tile beside the name, never the name itself. Each profile is a flat clickable Card in a horizontal List: the network's name is the one link, and the card's clickable affordance spreads it over the whole tile, so the target is the tile rather than a line of text. Compact tightens the row and takes the small icon tile. The icon key comes from the shared library, so switching library never rewrites a record.
